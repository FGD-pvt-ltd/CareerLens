01 · Problem Space Industry & Campus Friction

The Employability Disconnect: Claims vs. Proof

Why traditional resumes, ATS keyword matchers, and unverified profiles fail modern engineering hiring.

01 · The Student Dilemma
  • Keyword Stuffing Trap: Students list 20+ technologies to bypass ATS filters, masking their true technical proficiency.
  • Fragmented Identity: Proof of work is scattered across GitHub, LeetCode, portfolios, and course certificates with zero unified view.
  • Reactive Rejections: Students only discover critical skill deficits after failing technical placement rounds when it is too late to fix.
02 · Placement Bottlenecks
  • Batch Review Overload: Placement cells must evaluate 1,000+ graduating students, relying on high-level GPA rather than code readiness.
  • Zero Cohort Telemetry: Institutions lack aggregated data to identify batch-wide technology deficits before hiring drives start.
  • Mismatched Referrals: Students are routed to unsuitable hiring partners, resulting in poor placement conversion rates.
03 · Recruiter Distrust
  • Low Signal-to-Noise: 70%+ of applicants with polished resumes fail basic architectural and practical coding evaluations.
  • Manual Verification Burden: Engineering managers spend hours auditing GitHub repos, commit histories, and code quality manually.
  • Expensive Mis-Hires: Relying on self-reported resume claims creates inflated interview funnels and high recruitment rework.
The Root Cause: "A resume is an unverified claim. A GitHub repo is raw data."
No existing platform automatically cross-references self-reported skills against demonstrable code proof to generate an explainable, benchmarked readiness score with actionable remediation.

02 · Proposed Solution System Blueprint

ProfiQ: Evidence-Based Employability Intelligence

An end-to-end AI platform that converts raw developer claims into verifiable career readiness.

1. Ingest & Aggregate
  • Resume Ingestion: PDF parsing extracts candidate bio, education, claimed skills, and projects into structured JSON.
  • Developer Telemetry: Fetches live GitHub repositories, language distributions, and commit frequency.
  • Target Role Selection: Candidate selects intended role benchmark (Frontend, Backend, Full Stack, or ML Engineer).
2. AI Verify & Benchmark
  • Artifact Cross-Check: Google Gemini cross-references claimed skills against actual repo code & dependencies.
  • Confidence Scoring: Separates verified proof from unbacked claims using deterministic heuristics.
  • Role Matrix Comparison: Evaluates depth against standardized critical, recommended, and optional skill matrices.
3. Quantify & Remediate
  • Readiness Score (0–100): Transparent, explainable metric combining skill fit (60%) and proof depth (40%).
  • Gap Identification: Pinpoints exact missing technical dependencies required for target roles.
  • Milestone Roadmap: Generates structured 4-week learning sprints with curated project objectives.
Why It Is Better: Evidence Over Keywords

Unlike traditional ATS checkers that only perform shallow string matching, ProfiQ establishes ground truth by inspecting actual repository commits, code architecture, and package manifests to verify whether a candidate can genuinely execute.

The Innovation: Actionable Career Remediation

ProfiQ transforms evaluation from a passive 'judgment' into an active developmental roadmap. Students receive transparent explanations for every deducted point and a prescriptive milestone plan to turn red skill deficits into verified green badges.

04 · Evaluation Logic Deterministic Metrics

Evidence-Based Mathematical Scoring Methodology

A transparent, explainable formula that rewards verified engineering competence and penalizes unbacked claims.

Readiness Score (R) = (Skill Match × 0.60) + (Evidence Verification × 0.40)
Where: S = Skill Match Score (0–100) based on industry role benchmarks | E = Evidence Verification Score (0–100) based on code proof
1. Skill Match Score (S · 60% Weight)
  • Hierarchical Role Weights: Evaluates skills against curated industry matrices according to role criticality:
  • • Critical Skills (1.0× Weight): Foundational technologies without which candidate cannot operate (e.g., React & JS for Frontend).
  • • Recommended Skills (0.7× Weight): Modern production tooling that elevates output (e.g., TypeScript, Tailwind, REST APIs).
  • • Optional Skills (0.4× Weight): Value-add proficiencies (e.g., Docker, GraphQL, Jest).
  • Coverage Ratio: Normalizes candidate skills directly against active industry requirements.
2. Evidence Verification Score (E · 40% Weight)
  • Evidence Confidence Hierarchy: Each claimed skill is assigned an evidence tier backed by observable data:
  • • High Confidence (0.85 – 1.0): Public repo with verified commits, active velocity, and matching codebase.
  • • Moderate Confidence (0.50 – 0.70): Listed academic project, course certification, or live portfolio demo URL.
  • • Low / Unbacked (0.10 – 0.30): Resume keyword claim with zero observable proof or commit history.
  • Penalty Mechanism: Unbacked claims dilute the overall score, directly discouraging resume exaggeration.

06 · Defensibility & Horizon Market Strategy & Growth

Feasibility, Competitive Moat & Growth Horizon

Low operational run-rates, clear unfair advantages over legacy tools, and a defined post-hackathon roadmap.

Competitive Moat
  • Traditional ATS: Parses resume strings blindly; easily gamed by buzzword stuffing with zero evidence verification.
  • LinkedIn Profiles: Relies solely on unverified self-reporting and social endorsements without code audits.
  • Generic AI Chatbots: Provides generic advice without ingesting authentic developer artifacts or scoring mathematically.
  • ProfiQ Advantage: Only platform combining multi-platform proof of work + benchmark alignment + automated remediation.
Feasibility & Economics
  • Minimal API Costs: Structured JSON prompts and token optimization keep LLM execution costs to fractions of a cent per profile.
  • Deterministic Caching: Caches GitHub repository metadata and benchmark matrices to eliminate redundant API calls.
  • Zero Infrastructure Barrier: Built on lightweight Node.js and MongoDB; easily deployed to serverless environments.
  • Privacy & Security: Inspects only public code artifacts; no intrusive access to private student credentials.
Future Development Horizon
  • Phase 1: Multi-Platform Ingestion: Expand connectors to LeetCode, Codeforces, HackerRank, and GitLab for algorithmic telemetry.
