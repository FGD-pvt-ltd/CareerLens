# ProfiQ — Hackathon Demo Flow

## Recommended Presentation Walkthrough

1. **Problem Context (30 seconds):**
   - Address the challenge of keyword-stuffed resumes and lack of reliable, evidence-backed employability metrics for students and placement cells.

2. **Step 1: Candidate Profile Ingestion (1 minute):**
   - Upload candidate resume.
   - Enter candidate credentials (e.g. GitHub handle, portfolio link) and select target role (e.g., *Frontend Developer*, *Software Engineer*).

3. **Step 2: AI Verification & Analysis Pipeline (1 minute):**
   - Trigger the AI Engine pipeline.
   - Show how the AI extracts skills, cross-references GitHub commit history/code artifacts for proof, and matches against standardized industry benchmarks.

4. **Step 3: Results & Gap Analysis (1.5 minutes):**
   - Showcase the overall Employability Readiness Score.
   - Examine the verified vs unbacked skills breakdown.
   - Highlight critical skill gaps relative to the role benchmark.

5. **Step 4: Actionable Milestone Roadmap (1 minute):**
   - Present the personalized learning & project milestone plan generated to close candidate skill gaps.

6. **Step 5: Institutional & Placement Cell Insights (1 minute):**
   - Overview of batch readiness distribution and student intervention metrics.
