# SkillProof — Hackathon Demo Flow (DataQuest 3.0)

## Recommended Presentation Walkthrough

1. **Problem Context (30 seconds):**
   - Highlighting the challenge of keyword-stuffed resumes and lack of reliable readiness metrics for college placement cells.

2. **Step 1: Student Profile Ingestion (1 minute):**
   - Upload candidate resume (`.pdf`).
   - Enter GitHub username and target dream role (e.g., *Frontend Developer*).

3. **Step 2: AI Verification & Analysis (1 minute):**
   - Trigger the analysis pipeline.
   - Show how the AI Engine extracts skills, queries GitHub repositories for proof, and matches against the role schema.

4. **Step 3: Results & Gap Analysis (1.5 minutes):**
   - Display the overall Readiness Score.
   - Examine the verified vs unbacked skills breakdown (`EvidenceCard`).
   - Highlight missing skills (`GapAnalysis`).

5. **Step 4: Actionable Milestone Roadmap (1 minute):**
   - Present the 6-week personalized project and study plan generated to bridge the gap.

6. **Step 5: Placement Cell / Institutional Dashboard (1 minute):**
   - Showcase batch-level readiness analytics for placement officers and universities.
